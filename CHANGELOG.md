## [1.0.0] - 2026-09-02

### Added
- Initial release of NLP Engineering Week 5 module
- Topic 1: Tokenization
  - Word tokenization using NLTK
  - Sentence tokenization using NLTK
  - Practical examples with real text data

- Topic 2: Stopwords Removal
  - English stopwords filtering
  - Punctuation removal
  - Text cleaning pipeline

- Topic 3: Keyword Extraction
  - Frequency-based keyword identification
  - Dictionary building and analysis
  - Top keyword detection

- Topic 4: Stemming
  - Porter Stemmer implementation
  - Word reduction to root form
  - Morphological analysis

- Topic 5: Lemmatization
  - WordNet Lemmatizer integration
  - Part-of-speech based lemmatization
  - Semantic word normalization

- Topic 6: N-Grams
  - Unigram generation
  - Bigram generation
  - Trigram generation
  - Sequence analysis

- Topic 7: Bag of Words
  - CountVectorizer implementation
  - Vocabulary building
  - Document-term matrix creation
  - Feature extraction for ML models
